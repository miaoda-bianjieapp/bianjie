# 共享工具开发表字段说明

本文只定义共享工具开发表中的两张表及字段含义，供开发者、管理员和 AI 在创建工具 Issue 时生成记录草稿。

## 1. 记录数量规则

- 一个合规 Issue 默认且只对应 1 条任务表记录。
- 一条任务记录可以包含同一 Tab、同一分类、同一能力族的 1-3 个工具。
- 如果需要不同负责人、不同分支、不同 PR 或不同能力族，必须拆分 Issue。
- 迁移占用表记录数量等于本 Issue 计划新增的 Flyway SQL 文件数量，不等于工具数量。
- 无 Flyway 文件填 0 条；一个 Flyway 文件填 1 条；多个 Flyway 文件逐条填写。

## 2. 任务表结构

| 任务 ID / Task ID | 开发者 / Owner | 工具与 Tab / Tools and Tab | toolId | executor / operation | 分支 / Branch | 公共文件占用 / Shared Ownership | 数据库与 Flyway / DB and Flyway | Issue | PR | 状态 / Status | 最后更新 / Updated |
|---|---|---|---|---|---|---|---|---|---|---|---|
| 待管理员分配 |  |  |  |  | 待管理员批准 |  |  | 当前 Issue | - | 需求确认 |  |

### 任务表字段说明

- **任务 ID**：管理员批准 Issue 后分配的稳定编号，例如 TOOL-021；Issue 草稿阶段填写“待管理员分配”。
- **开发者**：唯一负责人，填写 GitHub 用户名和姓名。
- **工具与 Tab**：填写 Tab、分类、工具中文名和真实可用目标。多个工具在同一单元格分行填写。
- **toolId**：每个工具对应的 tools.id。Issue 草稿阶段填写候选 ID；开发者提交 Issue 前自行查询 PostgreSQL 是否重复。多个 ID 分行填写。
- **executor / operation**：填写能力族 executor 和每个工具的 operation。多个工具分行填写。
- **分支**：管理员批准的个人分支；Issue 草稿阶段填写“待管理员批准”。
- **公共文件占用**：预计修改且可能被其他任务同时修改的共享执行器、协议 DTO、动态表单、历史附件结构、公共页面或共享组件。
- **数据库与 Flyway**：说明无迁移、结构迁移、配置数据迁移或待确认，并概述表、字段、索引或配置变化。
- **Issue**：当前 GitHub Issue 编号或链接；草稿阶段填写“当前 Issue”。
- **PR**：PR 尚未创建时填写“-”，创建后填写编号或链接。
- **状态**：Issue 草稿阶段填写“需求确认”；后续由管理员维护。
- **最后更新**：共享表实际登记或状态更新日期。

## 3. Flyway 迁移占用表结构

| 任务 ID / Task ID | 开发者 / Owner | 迁移目的 / Purpose | 开发阶段文件 / Draft File | 最终 Flyway 文件 / Final Migration | 依赖版本 / Depends On | 是否在共享库执行 / Applied to Shared DB | 状态 / Status |
|---|---|---|---|---|---|---|---|
| 待管理员分配 |  |  |  | 待管理员批准 | 当前最新迁移 / 待管理员确认 | 否 / No | Draft |

### 迁移表字段说明

- **任务 ID**：与任务表相同；一个 Issue 有多个迁移文件时，多条记录使用同一个 Task ID。
- **开发者**：负责实现和测试该迁移的开发者。
- **迁移目的**：说明为什么需要迁移，以及会修改哪些表、字段、索引、约束或配置数据。
- **开发阶段文件**：可填写 docs/migration-drafts/<TASK>__description.sql；无草稿文件时填写“-”。
- **最终 Flyway 文件**：Issue 草稿阶段填写“待管理员批准”。最终使用 VyyyyMMddHHmmss__lowercase_description.sql。
- **依赖版本**：说明该迁移必须在哪个已有迁移之后执行；草稿阶段可填写“当前最新迁移 / 待管理员确认”。
- **是否在共享库执行**：Issue 和开发阶段填写“否”；在共享测试库、预发布库或生产库执行后由管理员更新为“是”。
- **状态**：可使用 Draft、等待依赖、PR 审查中、已合并待执行、已执行并锁定。
